Welcome to the MC server website!

This is the official website for Lunya's Minecraft server! This is a semi-survival vanilla Minecraft server made to be mainly fun. The IP is lunya.pet and any Minecraft version between 1.7.2 and 1.21.11 will work, although we recommend the latest one as that's what the server is on.

We have the following plugins installed:

  • Essentials for better admin commands, player chat, warps, homes etc.
  • CoreProtect to revert griefs
  • WorldGuard to protect player builds, and spawn
  • FAWE for world editing
  • AuthMe fork for player auth
  • LWC for locking your belongings
  • WildRTP for random teleportation
  • Skript for more custom things, right now used for various social commands
  • Fast Leaf Decay
  • AxGraves to prevent players killing each other, and prevent items despawning for a while
  • SkinsRestorer for players to have skins

Anything that is highly requested and is a good idea will be added into this list and installed on the server.
