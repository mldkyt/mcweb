Commands

The server has many plugins and many commands that can be used by an average player.

Homes

You can set up to 3 homes. Use the /sethome command with a name to set a home, and /home command to teleport to a home.

Warps

You can ask admins if you want to set warps to landmarks and similar stuff. Use the /warp command to teleport to a warp. Some warps are available as signs on spawn.

LWC

Locking your own belongings can be done by using /lock command and then punching a chest. You can change settings using commands beginning in /c such as /cautoclose to enable auto closing of doors. /cdonation and /csupply are useful commands for chests. You can password-lock a chest instead of a private lock by using /cpassword

RTP

There's an RTP command. Use the /rtp command to teleport to a random location.

Skin changing

Since this server is cracked, skins are provided by SkinsRestorer. You can use the /skin set and then the username to set another player's skin. You can find skins on namemc, typically next to skins are player names.

Messaging

The /w and /msg commands should allow messaging players, quick reply using /r should work too.

Other commands

/social, /discord, /xmpp, /matrix and a few others I can't list from my memory bring up social links you can use to get in contact with other people. I recommend Discord as I'm currently the most active there.

Stuff might be missing here so please ping me if there's something important missing.
